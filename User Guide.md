# User Guide — Advanced Task Manager

## Вкладка Details
Отображает список всех активных процессов:
- PID — идентификатор процесса
- Название — имя исполняемого файла
- Использование памяти (МБ)
- Использование CPU (% от общего ресурса)

### Функции:
- Сортировка: по каждому столбцу, повторный клик меняет порядок
- Контекстное меню:
  - Просмотр деталей — расширенная информация о процессе
  - Завершить процесс — остановка выбранного процесса (может потребоваться запуск от администратора)

## Вкладка Performance
Показывает графики в реальном времени (обновление раз в секунду), доступны метрики:
- Загрузка CPU (%)
- Использование оперативной памяти (%)
- Загрузка GPU (%), если обнаружена поддерживаемая NVIDIA GPU

### Особенности:
- Автоматическое масштабирование графиков
- История до 60 секунд
- Переключение между графиками с помощью кнопок

User Guide Task Manager 

1) Вкладка «Details» 
Список процессов: 
Отображает все запущенные процессы с: 
- PID (идентификатор процесса) 
- Имя процесса 
- Использование памяти (в МБ) 
- Использование CPU (в процентах от общего CPU) 
Функции: 
-	Сортировка: Нажмите на заголовок любого столбца для сортировки. Нажмите снова для обратной сортировки. 
-	Контекстное меню (ПКМ на процессе): 
		1)	Просмотр деталей: Показывает дополнительную информацию о выбранном процессе 
		2)	Завершить процесс: Останавливает выбранный процесс (требует соответствующих прав) 

2) Вкладка «Performance» 
Графики в реальном времени: Визуализация использования системных ресурсов 
Три доступных метрики: 
	- Использование CPU (%) 
	- Использование оперативной памяти (%) 
	- Использование GPU (%) !(если обнаружено поддерживаемое оборудование) 
Управление графиками: 
Используйте кнопки вверху для переключения между метриками 
! Графики автоматически обновляются каждую секунду 
! Отображается до 60 точек данных (1 минута истории)

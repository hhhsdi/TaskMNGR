# Документация проекта

## Архитектура
Программа разделена на два основных уровня:
1. Сбор данных: C++ DLL (`Dll3.dll`)
2. Отображение и управление: Python GUI (`GUI.py`)

## main.py
Модуль фонового мониторинга процессов.

### Класс: TaskMngrInfo
- `pid: int`
- `name: str`
- `memory: float` — в МБ
- `cpu: float` — в %

Метод:
- `__repr__()` — текстовое представление процесса

### Основные функции:
- `get_process_info()` — получает список активных процессов
- `monitoring_system()` — выводит данные в консоли каждые 5 секунд
- `start_monitoring()` — запускает мониторинг в отдельном потоке

## GUI.py
Интерфейс диспетчера задач.

### Класс: TaskManagerGUI
Инициализация:
```python
TaskManagerGUI(tk.Tk())
```

### Основные компоненты:
- Вкладка Details — таблица процессов
- Вкладка Performance — графики CPU, RAM, GPU

### Ключевые методы:
- `create_widgets()` — формирует структуру интерфейса
- `create_details_tab()` — список процессов с сортировкой и меню
- `create_performance_tab()` — графики производительности
- `refresh_process_list()` — обновление таблицы
- `kill_selected_process()` — завершение процесса
- `show_process_details()` — подробности о процессе
- `switch_graph(graph_type)` — смена графика (CPU, Memory, GPU)
- `update_performance_charts()` — обновление графиков
- `on_close()` — корректное завершение

### Автоматизация:
- Обновление списка процессов: каждые 3 секунды
- Обновление графиков: каждую секунду

## process_wrapper.py
Мост между Python и C++:
- Загружает `Dll3.dll`
- Преобразует структуры C в Python
- Обрабатывает указатели, массивы и строки

## API DLL (Dll3.dll)

### Основные структуры:
```c
typedef struct {
    unsigned long pid;
    wchar_t name[260];
    double cpuUsage;
    double memoryMB;
} ProcessInfo;

typedef struct {
    wchar_t name[256];
    float usagePercent;
    float memoryUsedMB;
    float memoryTotalMB;
} GpuInfo;
```

### Экспортируемые функции:
```c
int GetProcessesInfo(ProcessInfo** processes);
void FreeProcessesInfo(ProcessInfo* processes);
int KillProcess(unsigned long pid);

float GetTotalCPUUsage();
float GetTotalMemoryUsage();

void InitGpuMonitor();
int GetGpuInfo(GpuInfo* info);
void CleanupGpuMonitor();
```

## Ограничения
- Работает только в Windows
- Для GPU необходима NVIDIA и pynvml
- Завершение некоторых системных процессов может быть недоступно

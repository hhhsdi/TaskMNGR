Этот проект представляет собой диспетчер задач с графическим интерфейсом, который отображает информацию о процессах, потреблении CPU, памяти и GPU. 
Проект состоит из двух основных файлов:
1. main.py - содержит логику работы с процессами и их мониторинга
2. GUI.py - содержит графический интерфейс на основе Tkinter

1) Файл main.py:

Классы: 
- TaskMngrInfo - Класс для хранения информации о процессе.
    Атрибуты:
    - pid (int) - идентификатор процесса
    - name (str) - имя процесса
    - memory (float) - использование памяти в MB
    - cpu (float) - использование CPU в процентах

    Методы:
    __repr__() - возвращает строковое представление объекта

    Функции:
    * get_process_info() - Собирает информацию о всех запущенных процессах.
        Возвращает:
        Список объектов TaskMngrInfo, содержащих информацию о каждом процессе

    * monitoring_system() - Функция для мониторинга процессов в фоновом режиме. Выводит информацию о процессах каждые 5 секунд.

    * start_monitoring() - Запускает мониторинг процессов в отдельном потоке.

2) Файл GUI.py:

Классы:
- TaskManagerGUI
    Основной класс графического интерфейса диспетчера задач.

    Атрибуты:
    - Различные настройки интерфейса и параметры обновления
    - Данные для графиков (CPU, Memory, GPU)
    - Обработчики GPU (если доступны)

    Основные методы:
    * __init__(root) - Инициализирует графический интерфейс.
    Параметры:
    root - корневое окно Tkinter

    * create_widgets() - Создает все элементы интерфейса, включая вкладки и кнопки.

    * create_details_tab() - Создает вкладку с детальной информацией о процессах.

    * create_performance_tab() - Создает вкладку с графиками производительности.

    * switch_graph(graph_type) - Переключает между графиками CPU, Memory и GPU.
    Параметры:
    graph_type - тип графика ("CPU", "Memory" или "GPU")

    * refresh_process_list() - Обновляет список процессов с сохранением текущей сортировки.

    * update_performance_charts() - Обновляет данные на графиках производительности.

    * kill_selected_process() - Завершает выбранный процесс.

    * show_process_details() - Показывает детальную информацию о выбранном процессе.

    * sort_column(column, reverse) - Сортирует процессы по указанной колонке.
    Параметры:
    column - колонка для сортировки
    reverse - направление сортировки

    * on_close() - Обработчик закрытия окна, выполняет очистку ресурсов.

    Вспомогательные функции:
    * run_gui() - Запускает главное окно приложения.

Особенности:
- Автоматическое обновление списка процессов каждые 3 секунды
- Обновление графиков производительности каждую секунду
- Поддержка GPU (если доступно)
- Сортировка процессов по различным параметрам
- Возможность завершения процессов
- Подробная информация о каждом процессе

Ограничения:
- Для работы с GPU требуется библиотека pynvml и совместимая видеокарта NVIDIA
- Некоторые системные процессы могут быть недоступны для завершения

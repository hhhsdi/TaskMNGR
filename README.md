Проект представляет собой диспетчер задач с графическим интерфейсом, отображающий информацию о процессах и потреблении системных ресурсов (CPU, памяти, GPU). Состоит из двух основных модулей:

1. `main.py` - ядро системы мониторинга процессов
2. `GUI.py` - графический интерфейс на Tkinter

## Основной модуль (main.py)

### Классы
**TaskMngrInfo**  
Хранит информацию о процессе:
- `pid` - идентификатор процесса (int)
- `name` - название процесса (str)
- `memory` - использование памяти в МБ (float)
- `cpu` - загрузка CPU в % (float)

Методы:
- `__repr__()` - строковое представление объекта

### Функции
**get_process_info()**  
Собирает данные о всех активных процессах  
Возвращает: список объектов TaskMngrInfo

**monitoring_system()**  
Фоновая проверка процессов с выводом данных каждые 5 секунд

**start_monitoring()**  
Запускает мониторинг в отдельном потоке

## Графический интерфейс (GUI.py)

### Основной класс
**TaskManagerGUI**  
Главное окно приложения

Основные компоненты:
- Настройки интерфейса
- Данные для графиков (CPU/память/GPU)
- Интеграция с GPU (при наличии)

### Ключевые методы
- `create_widgets()` - Создает элементы интерфейса
- `create_details_tab()` - Формирует вкладку с процессами
- `create_performance_tab()` - Создает вкладку с графиками 
- `refresh_process_list()` - Обновляет список процессов 
- `kill_selected_process()` - Завершает выбранный процесс 

**Ключевые методы:**

**Инициализация:**
- `__init__(root)` - настройка окна, инициализация данных, создание виджетов
- `create_widgets()` - основной метод создания интерфейса

**Работа с процессами:**
- `refresh_process_list()` - обновляет список процессов с сохранением сортировки
- `sort_column(column, reverse)` - сортировка по указанной колонке
- `kill_selected_process()` - завершает выбранный процесс
- `show_process_details()` - показывает детали процесса

**Графики производительности:**
- `setup_performance_charts()` - инициализация графиков
- `update_performance_charts()` - обновление данных графиков
- `switch_graph(graph_type)` - переключение между графиками CPU/Memory/GPU
- `update_graph_display()` - отрисовка текущего графика

**Вспомогательные методы:**
- `setup_auto_refresh()` - настройка автоматического обновления
- `show_context_menu(event)` - обработка контекстного меню
- `on_close()` - обработчик закрытия окна (очистка ресурсов)

### Особенности работы
- Автообновление данных:
  - Список процессов: каждые 3 секунды
  - Графики: каждую секунду
- Поддержка GPU (требуется pynvml и видеокарта NVIDIA)
- Сортировка по всем колонкам
- Защита системных процессов

## Руководство пользователя

### Вкладка "Процессы"
Отображает:
- PID процесса
- Название
- Потребление памяти (МБ)
- Нагрузку на CPU (%)

Функционал:
1. **Сортировка** - клик по заголовку столбца
2. **Контекстное меню** (ПКМ на процессе):
   - Просмотр деталей
   - Завершение процесса (требует прав)

### Вкладка "Производительность"
Графики в реальном времени:
- Загрузка CPU (%)
- Использование памяти (%)
- Использование GPU (%)*

Управление:
- Переключение между графиками кнопками
- История данных: 60 точек (1 минута)
- Автообновление: каждую секунду
*Только при наличии поддерживаемого GPU NVIDIA

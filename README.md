# Advanced Task Manager


## Описание

Advanced Task Manager — это графическое приложение для мониторинга системных ресурсов и управления процессами. Программа предоставляет:

- Список запущенных процессов с информацией о PID, имени, использовании CPU и памяти
- Графики в реальном времени для CPU, RAM, GPU и памяти GPU
- Возможность завершения процессов
- Детальную информацию о выбранном процессе

## Функциональность

- **Вкладка "Processes"**:
  - Таблица процессов с сортировкой по колонкам
  - Контекстное меню для просмотра деталей или завершения процесса
  - Отображение общего использования CPU, RAM и GPU

- **Вкладка "Performance"**:
  - Графики использования CPU, RAM, GPU и памяти GPU
  - Обновление данных в реальном времени

## Использование

1. **Просмотр процессов**:
- Процессы автоматически обновляются каждые 3 секунды
- Сортировка по колонкам при нажатии на заголовок

2. **Управление процессами**:
- Правый клик на процессе открывает контекстное меню
- Выберите "Show Details" для просмотра информации
- Выберите "End Process" для завершения процесса

3. **Мониторинг производительности**:
- Перейдите на вкладку "Performance" для просмотра графиков
- Данные обновляются каждую секунду

## Особенности реализации

- Использует собственный DLL для получения системной информации
- Многопоточный сбор данных о производительности
- Интерактивные графики с помощью Matplotlib
- Сортировка таблицы процессов по различным параметрам
